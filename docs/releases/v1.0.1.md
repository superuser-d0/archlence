# Archlence v1.0.1

## Bu sürümde düzeltilenler

- Varlık ekleme işlemi artık portföy kaydı, hesap işlemi, bakiye değişimi ve
  ledger olayını tek atomik transaction olarak kaydeder.
- Kayıt başarılı olduktan sonra oluşabilecek UI yenileme hataları kullanıcıya
  yanlış “varlık eklenemedi” mesajı göstermez.
- Eklenen varlık manuel yenileme gerektirmeden listede görünür; portföy,
  işlem geçmişi ve grafik yenilemeleri ana UI thread’ine ayrı görevler olarak
  gönderilir.
- Hızlı çift tıklama çift kayıt üretmez.
- Altın ekleme ve BIST 100 seçim dialogları küçük pencerelerde başlık veya
  aksiyon butonlarıyla çakışmaz.

## Kurulum

Windows: `ArchlenceSetup-1.0.1.exe` dosyasını çalıştırın.

Linux:

```bash
chmod +x Archlence-1.0.1-x86_64.AppImage
./Archlence-1.0.1-x86_64.AppImage
```

## Veri ve uyumluluk

Bu patch release veri şemasını değiştirmez ve v1.0.0 kullanıcı verileriyle
geriye uyumludur. Mevcut `v1.0.0` release’i ve tag’i değiştirilmemiştir.

Veriler cihazınızda tutulur. Anahtar koruma, doğrulanmış backup/restore ve
legacy migration davranışları v1.0.0 ile aynıdır.

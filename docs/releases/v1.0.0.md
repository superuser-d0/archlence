# Archlence v1.0.0

## Archlence nedir?

Archlence, verilerini kullanıcının cihazında tutan local-first kişisel finans
masaüstü uygulamasıdır.

## Desteklenen platformlar

- Windows 10/11, 64 bit installer
- 64 bit Linux AppImage

Yalnız release kalite raporunda başarıyla doğrulanan ortamlar desteklenmiş
sayılır.

## Öne çıkan özellikler

- Gelir, gider, hesap, kredi kartı, bütçe ve birikim yönetimi
- Tekrarlanan gelir/gider ve abonelik takibi
- Portföy, finansal sağlık ve senaryo analizleri
- Yerel PIN, tema ve Türkçe/İngilizce arayüz

## Güvenlik ve veri bütünlüğü

- Şifreleme başarısızsa hassas veri kaydedilmez; düz metin fallback yoktur.
- AEAD bütünlük doğrulamasını geçmeyen kayıtlar `0` sayılmaz ve toplamları
  geçersiz kılar.
- Legacy kayıt migration’ı doğrulanmış backup, transaction ve rollback kullanır.
- Windows anahtarı DPAPI ile; Linux anahtarı kullanılabilirse Secret
  Service/KWallet ile korunur. Güvenli depo yoksa 0600 dosya fallback’i
  Ayarlar ekranında açıkça gösterilir.
- Backup, veritabanını ve parola korumalı kurtarma materyalini birlikte taşır;
  restore öncesinde DB/anahtar eşleşmesi doğrulanır.
- Anahtar ve kurtarma parolası birlikte kaybedilirse şifreli veriler
  kurtarılamaz.

## UI iyileştirmeleri

- Arama alanındaki dikey birleşim çizgisi kaldırıldı.
- Pencerenin sağındaki gereksiz scrollbar çizgisi kaldırıldı.
- Cursor yalnız gerçek focus durumunda ve metnin giriş noktasında çizilir.
- Açık/koyu tema, normal/2× DPI, yeniden boyutlandırma ve tam ekran için
  tekrarlanabilir görsel kontrol eklendi.

## Kurulum

Windows: `ArchlenceSetup-1.0.0.exe` dosyasını çalıştırın.

Linux:

```bash
chmod +x Archlence-1.0.0-x86_64.AppImage
./Archlence-1.0.0-x86_64.AppImage
```

## Veri konumu

- Windows: `%LOCALAPPDATA%\Archlence`
- Linux: `~/.local/share/Archlence`

Log ve cache dizinleri platformun standart kullanıcı dizinlerindedir.

## Backup ve recovery

Uygulama içindeki “Veriler ve Gizlilik” menüsünden doğrulanmış backup
oluşturun. Backup parolasını paketten ayrı saklayın. Yalnız `finance.db`
dosyasını kopyalamak, şifreleme anahtarı olmadan yeterli değildir.

## Bilinen sınırlamalar

- Finansal piyasa fiyatları harici veri sağlayıcılarına bağlıdır.
- Linux güvenli anahtar deposu masaüstü oturumunda Secret Service/KWallet
  bulunmasına bağlıdır; aksi durum kullanıcıya bildirilen dosya fallback’idir.
- Bu uygulama banka, aracı kurum veya profesyonel finansal danışman değildir.

## Kod imzalama

Paketler kod imzalı değildir. Windows SmartScreen veya Linux masaüstü
ortamınız kaynakla ilgili uyarı gösterebilir.

## Dosya doğrulama

İndirdiğiniz dosyaları `SHA256SUMS.txt` ile doğrulayın:

```bash
sha256sum -c SHA256SUMS.txt
```

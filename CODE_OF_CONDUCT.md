# Code of conduct

Archlence welcomes people who contribute code, testing, documentation,
translation, design feedback, and careful bug reports.

## Expected behavior

- Be respectful, patient, and specific when giving feedback.
- Discuss the work and its evidence, not the person doing it.
- Make room for different experience levels and language backgrounds.
- Respect privacy: never pressure someone to share real financial data,
  credentials, keys, recovery material, or identifying screenshots.
- Treat security findings and accidental sensitive-data exposure discreetly.
- Accept maintainers' decisions on project scope while remaining free to offer
  a reasoned alternative.

## Unacceptable behavior

Harassment, discrimination, threats, sexualized attention, deliberate
misgendering, doxxing, personal attacks, sustained disruption, and publishing
another person's private information are not acceptable. Neither is using
financial or security data disclosed by mistake for any purpose beyond helping
the person remove it safely.

## Reporting and enforcement

For ordinary conduct concerns, email `Superkullaniciyapiyor@proton.me`. For
security-sensitive concerns, use the process in [SECURITY.md](SECURITY.md).
Do not post private evidence in a public issue.

Maintainers may edit or remove comments, close discussions, reject
contributions, or temporarily or permanently restrict participation when
behavior threatens the community or project. Reports will be handled as
privately as the available GitHub tools allow; no response-time guarantee is
made.

This code applies to project repositories, issues, pull requests, discussions,
and other spaces where someone is representing Archlence.
